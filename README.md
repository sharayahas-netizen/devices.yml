# استبيان رضا نزلاء الفندق 🏨

نظام استبيان يعمل على سيرفرك الخاص: كل غرفة لها رمز QR خاص بها، النزيل يمسح الرمز من جواله ويقيّم الغرفة والفندق والمطعم. **لا يمكن تعبئة استبيان الغرفة مرتين** — بعد التعبئة تُقفل الغرفة تلقائياً لمدة 24 ساعة (قابلة للتعديل) ثم تُفتح للنزيل التالي، ويمكن للاستقبال فتحها يدوياً في أي وقت.

- واجهة النزيل: **عربي + إنجليزي** (النزيل يبدّل اللغة بضغطة زر)
- لوحة تحكم للإدارة: إحصائيات، قراءة الإجابات، إدارة الغرف، طباعة رموز QR، تصدير Excel
- قاعدة بيانات SQLite مدمجة — لا تحتاج تنصيب أي قاعدة بيانات منفصلة

## المتطلبات

- سيرفر لينكس (أو ويندوز) عليه **Node.js إصدار 22.5 أو أحدث**

## التنصيب على السيرفر

```bash
# 1) انسخ المشروع إلى السيرفر ثم:
cd hotel-survey
npm install

# 2) شغّل البرنامج
npm start
```

سيعمل البرنامج على المنفذ 3000 (غيّره بمتغير البيئة `PORT=8080 npm start`).

## خطوات ما بعد التنصيب (مهم)

1. افتح `http://عنوان-سيرفرك:3000/admin`
2. سجّل الدخول بكلمة المرور الافتراضية: `admin123`
3. اذهب إلى **الإعدادات** فوراً و:
   - **غيّر كلمة المرور**
   - اكتب **اسم الفندق** بالعربي والإنجليزي
   - اكتب **رابط السيرفر** (العنوان الذي سيصل إليه النزلاء من جوالاتهم، مثل `http://192.168.1.10:3000` أو نطاقك) — هذا الرابط هو الذي يُوضع داخل رموز QR
4. أدخل غرف فندق القصر كلها بأمر واحد على السيرفر:
   ```bash
   npm run seed
   ```
   هذا يضيف 58 وحدة: الطابق الأول (101–113 + الغرفة الملكية)، الثاني (201–212)، الثالث (301–314)، الرابع (جناح 401 – جناح 406)، الخامس (501–512). ويمكنك دائماً إضافة أو حذف غرف من صفحة **الغرف**
5. اذهب إلى **رموز QR** واطبع الملصقات وعلّق كل ملصق في غرفته

> ملاحظة: يجب أن يكون السيرفر قابلاً للوصول من شبكة الواي فاي التي يستخدمها النزلاء (أو من الإنترنت إن أردت). للاستخدام عبر الإنترنت يُنصح بوضعه خلف Nginx مع شهادة HTTPS.

## التشغيل الدائم (systemd)

حتى يعمل البرنامج تلقائياً عند إعادة تشغيل السيرفر:

```bash
sudo cp deploy/hotel-survey.service /etc/systemd/system/
# عدّل مسار المشروع داخل الملف إذا اختلف عن /opt/hotel-survey
sudo systemctl daemon-reload
sudo systemctl enable --now hotel-survey
```

## أين تُحفظ البيانات؟

كل البيانات (الغرف، الإجابات، الإعدادات) في ملف واحد: `data/survey.db`. انسخ هذا الملف دورياً كنسخة احتياطية.

## كيف يعمل منع التكرار؟

- كل غرفة لها **توكن عشوائي فريد** في رابطها — لا يمكن تخمين رابط غرفة أخرى.
- عند إرسال الاستبيان تُسجَّل الغرفة كمقفلة في قاعدة البيانات **على السيرفر**، فلا يفيد النزيل تغيير الجهاز أو حذف سجل المتصفح.
- القفل ينتهي تلقائياً بعد المدة المحددة في الإعدادات (الافتراضي 24 ساعة)، ويمكن فكّه يدوياً من صفحة «الغرف».
